## Publish as a completely separate GitHub Pages website

1. Sign in to GitHub.
2. Create a **new, separate public repository** named `neha-bhardwaj`.
3. Upload this package's `index.html` file to the root of that new repository.
4. Open the new repository's **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to deploy the site.

Expected independent URL (after publication):
`https://p-mahajan1.github.io/neha-bhardwaj/`

This website is independent of the existing `bca-computer-fundamentals` repository and will not be added to that site.
